# Creative Playground pictures

Drop image files in this folder and they appear automatically in the
"Creative Playground" cloud on the home page. Supported: `.png`, `.jpg`,
`.jpeg`, `.webp`, `.gif`, `.avif`.

- **Order:** alphabetical by filename — prefix with numbers to control it,
  e.g. `01-daisy-sticker.jpg`, `02-xmas-card.png`.
- **Naming:** the filename becomes the image's alt text
  (`03-botox-party-flyer.jpg` → "botox party flyer"), so descriptive names
  are better than `IMG-1234.jpg`.
- **How many:** 6–12 images look best in the cloud.
- While this folder is empty, the section shows placeholder images from
  `src/data/playground.ts`.

If the dev server is running, save the file and refresh the page to see it.
